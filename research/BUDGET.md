# Budget & Burn

Token cost is a real cost to the Captain. Cheap tiers do volume; opus is reserved for judgment.

## Policy
- `numericist`, `analyst`, `replicator`, `auditor` → sonnet
- `librarian` → haiku/sonnet
- `theorist`, `red-team`, `referee`, `navigator` → opus (judgment is the product)
- Adversaries fire on **promotion attempts**, not every cycle
- Quiet cycles collapse as noops rather than generating chatter

## Circuit breakers
- Per-agent `maxTurns` caps set in each agent definition
- Captain checkpoint triggered if burn crosses threshold
